Import Data dari Google Sheets

Di Google Sheets, pilih File → Download → Comma-separated values (.csv). Lalu pilih file CSV di bawah.

Kolom yang dikenali untuk import kompetitor: name, category, city, website, contact, pic, ourCompany. Nama kolom boleh memakai label Indonesia seperti Nama Kompetitor, Kategori, Kota, Website, Kontak, dan PIC.

Jika nama kompetitor sudah ada, kamu dapat memilih memperbarui data atau melewati baris tersebut. Impor ini belum mengimpor detail cabang, skor observasi, atau gap analysis.
